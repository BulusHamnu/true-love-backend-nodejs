# Nodejs backend for true love app
## Website overview
True Love: When Two People Love Themselves Together

This project was built for David Prorok to help couples improve their relationships through guided programs and 1-on-1 coaching.
The app lets users:
- Book consultation calls with David
- Enroll in a 6-week transformation program on the app, with tracking, reflection section for $49
- Access course materials written by David to learn about relationship growth
- Optionally upgrade to an advanced 1-on-1 coaching package for $1200

## Technology used
- Lovable – for building the front-end interface
- Node.js / Express – for backend APIs and logic
- Stripe – to handle payments and subscriptions
- Resend – to send transactional and notification emails
